# 데스게임 보고서 한글 패치

**지원 게임 버전: The Death Game Report Windows판 1.0.5.** 게임이 업데이트되어 버전이 다르면 설치할 수 없습니다.

## 설치

1. 게임을 종료하고 [Releases](https://github.com/yoodong724/drepo-ko/releases)에서 `death-game-report-ko-v1.0.5.zip`을 받습니다.
2. `drepo.exe`와 `drepo.pck`가 있는 게임 폴더에 압축을 풉니다.
3. 생성된 `death-game-report-ko-v1.0.5` 폴더 안의 `install.cmd`를 실행합니다.

제거는 같은 폴더의 `uninstall.cmd`를 실행합니다. 별도 프로그램 설치는 필요 없습니다.

원본 게임 파일은 포함하지 않습니다. 소스 빌드는 [BUILD.md](BUILD.md)를 참고하세요.
